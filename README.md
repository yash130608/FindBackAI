# FindBack AI — HackBIOS 2K26

Complete Flask + SQLite college Lost & Found platform based on the supplied project brief.

## Features
- Report lost/found items with photo, category, location, date and time
- Student registration/login
- Search and filters
- Transparent weighted AI matching
- Possible-match notifications
- Claim workflow and owner verification
- Dashboard
- SQLite database with demo records
- Built-in FindBack AI campus assistant (no paid API required)
- Responsive UI suitable for future Android/iOS conversion

## Run in VS Code
```text
python -m venv venv
venv\\Scripts\\activate
pip install -r requirements.txt
python run.py
```
Then open http://127.0.0.1:5000

Demo: student@findback.local / student123
